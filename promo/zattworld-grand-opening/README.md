# ZATTWORLD SOLUTIONS — Grand Opening promo video

`zattworld_grand_opening_promo.mp4`: 30 s, 1080×1920 (9:16 vertical), 30 fps, H.264 + AAC. Ready for Facebook/Instagram Reels, Stories, WhatsApp Status and TikTok.

All details are copied from the printed invitation:
- Venue: Level 10, Akhtaruzzaman Center, 21/22 Agrabad C/A, Chattogram.
- Monday 28th Sep 2026, at 06:00 PM onwards
- Host: Md Akber Hossen, Chief Executive Officer (CEO)

The music is original and was generated by `music.py`, so it has no copyright issues.

## Re-render
```
npm i -g playwright   # uses the preinstalled Chromium
pip install imageio-ffmpeg numpy
ln -s "$(python3 -c 'import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())')" ffmpeg
PW=$(npm root -g)/playwright node render.js video   # -> video_silent.mp4
python3 music.py                                     # -> music.wav
./ffmpeg -i video_silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart zattworld_grand_opening_promo.mp4
```
To change text or timing, edit `promo.html` (each scene is timed in `render(t)`).
